# AI 브리핑룸 균형형 리뉴얼

## 결정

기존 Tech Insights Desk를 `AI 브리핑룸`으로 바꾸고, 콘텐츠 신뢰도와 빠른 탐색성을 함께 개선한다. 슬로건은 `일하는 사람의 AI 브리핑`이다.

## 선택한 방향

에디토리얼 리포트와 빠른 뉴스 브리핑을 결합한다. 따뜻한 종이색 배경, 잉크색 본문, 블루 포인트, 한국어 중심 타이포그래피를 사용한다. 최신 디자인 흐름의 표현력은 핵심 행동과 정보 구분에만 적용하며 글래스모피즘이나 장식용 블러는 사용하지 않는다.

## 핵심 사용자 흐름

```text
홈 진입
  → 오늘 꼭 볼 AI 이슈 확인
  → 업무 적용 아이디어 스캔
  → 3분 안에 핵심 글 선택
  → 글 상단 요약과 기준일 확인
  → 적용 방법과 주의점 확인
  → 원문 출처로 사실 검증
```

## 구현 범위

- 사이트 이름, 설명, 언어, 시간대, 내비게이션과 보조 문구 한국어화
- 홈 정보 구조와 게시물 카드 개편
- 글 상세의 메타 정보, 읽기 폭, 목차, 태그, 관련 글 개선
- 새 자동 생성 글의 표준 섹션과 제목 품질 기준 강화
- 잘못된 소셜 링크와 불필요한 외부 방문자 카운터 제거
- 라이트·다크 토큰, 포커스, reduced-motion, 모바일 반응형 개선

## 호환성

- 기존 Markdown frontmatter 스키마를 깨지 않는다.
- 과거 글은 새 레이아웃에서 그대로 렌더링한다.
- 새 필드가 필요하면 optional로 추가하고 기존 글에 기본값을 제공한다.
- 정적 Astro 배포와 Pagefind 검색 흐름을 유지한다.

## 성공 기준

- 첫 화면에서 최신 핵심 글과 업무 적용 가치가 바로 보인다.
- 모든 주요 UI 문구가 한국어로 통일된다.
- 새 글의 제목은 간결하고 지정된 편집 섹션을 포함한다.
- 320px부터 1440px까지 가로 넘침 없이 사용할 수 있다.
- 키보드 포커스와 색상 대비가 WCAG 2.2 AA 취지에 맞는다.
- Python 품질 테스트와 Astro check/build가 통과한다.
